# 我的待辦清單

專屬個人使用的待辦清單網頁應用。純 HTML / CSS / JavaScript，**沒有任何外部套件、不需要後端、不需要註冊帳號**，所有資料只存在你自己瀏覽器的 `localStorage` 裡。

## 怎麼開始用

**最簡單：** 下載這個專案，直接用瀏覽器打開 `index.html` 就能使用（可離線）。

**放到網路上（GitHub Pages）：**

1. 進入 GitHub repo 的 **Settings → Pages**
2. Source 選 **Deploy from a branch**，分支選這個專案的分支、資料夾選 `/ (root)`
3. 等一兩分鐘，就能用 `https://<你的帳號>.github.io/todo/` 開啟

> 注意：資料存在「開啟網頁的那個瀏覽器」裡。換裝置或換瀏覽器不會同步，請用下面的匯出／匯入功能搬移資料。

## 功能

- **新增／編輯／刪除**待辦事項，支援標題、備註、到期日、優先度（高／中／低）、分類
- **快速輸入語法**：在上方輸入框直接打字，一行搞定
  - `!高` `!中` `!低` → 設定優先度
  - `#工作` → 設定分類
  - `@今天` `@明天` `@後天` `@下週` `@2026-08-15` `@8/15` → 設定到期日
  - 例：`寫月報 !高 #工作 @明天`
- **篩選**：全部／未完成／今天／逾期／已完成，並可再依分類篩選
- **搜尋**：標題、備註、分類全文比對
- **排序**：自訂順序（可拖曳）、到期日、優先度、建立時間
- **統計**：待完成、今天到期、已逾期、已完成的數量
- **深色／淺色主題**：預設跟隨系統，可手動切換並記住選擇
- **匯出／匯入 JSON 備份**，以及清除已完成／刪除全部
- **刪除可復原**：刪除後畫面下方會出現「復原」按鈕
- **多分頁同步**：同一瀏覽器開多個分頁時會自動更新
- 響應式版面，手機、平板、桌機都能用

## 鍵盤快速鍵

| 按鍵 | 功能 |
| --- | --- |
| `N` | 聚焦到新增輸入框 |
| `/` | 聚焦到搜尋框 |
| `T` | 切換深色／淺色主題 |
| `Esc` | 關閉對話框／選單 |

## 檔案結構

```
index.html          畫面結構
assets/styles.css   樣式與主題變數
assets/app.js       所有應用邏輯（狀態、儲存、篩選、繪製）
```

## 資料格式

匯出的 JSON 長這樣，方便自行備份或搬移：

```json
{
  "version": 1,
  "exportedAt": "2026-08-02T00:00:00.000Z",
  "todos": [
    {
      "id": "…",
      "title": "寫月報",
      "note": "",
      "done": false,
      "priority": "high",
      "category": "工作",
      "due": "2026-08-03",
      "createdAt": 1754092800000,
      "doneAt": null
    }
  ]
}
```

匯入時會以 `id` 判斷重複並自動略過，所以同一份備份匯入兩次不會產生重複項目。

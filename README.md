# 打勾勾 Pinky

> 跟自己打勾勾，說到做到。

個人待辦清單網頁應用。純 HTML / CSS / JavaScript，**沒有任何外部套件、不需要後端、不需要註冊帳號**，所有資料只存在你自己瀏覽器的 `localStorage` 裡。

## 名字的由來

「打勾勾」在中文裡有兩層意思：打勾 ✓，還有拉小指的約定。待辦清單本來就是**跟自己的約定**——這也是整個 App 的核心概念：每一筆待辦都是一個約定，完成就是守約，累積下來就是你的「約定足跡」。

英文名 **Pinky**（pinky promise，打勾勾）。

## 怎麼開始用

**最簡單：** 下載這個專案，直接用瀏覽器打開 `index.html` 就能使用（可離線）。

**放到網路上（GitHub Pages）：**

1. 進入 GitHub repo 的 **Settings → Pages**
2. Source 選 **Deploy from a branch**，分支選這個專案的分支、資料夾選 `/ (root)`
3. 等一兩分鐘，就能用 `https://<你的帳號>.github.io/todo/` 開啟

> 資料存在「開啟網頁的那個瀏覽器」裡。換裝置或換瀏覽器不會同步，請用匯出／匯入搬移資料。

## 核心：信用系統與「勾勾」

打勾勾跟其他待辦 App 的差別：**別的 App 記你想做什麼，打勾勾記你說到做到了沒。** 你的行為累積成一份信用紀錄，而吉祥物「勾勾」——跟你拉過勾的那個傢伙——會照著這份帳跟你說話。

- **信用分**（0–100，開局 70）：準時完成 +2、補上遲到的 +1、補記 +1；改期扣分（次數越多扣越重）、逾期每天生利息、超貸 −3
- **額度**＝你能同時持有幾個進行中的約定，由信用分決定（85 分 18 件、70 分 12 件、40 分只剩 5 件）。**越會拖的人清單被迫越短**——短清單反而做得完，分數就回來了，系統自己會把人救回來
- **超貸**：超過額度仍可新增，但立刻扣分，勾勾會記上這筆
- **改期追討**：第三次改同一件事的到期日，勾勾直接問「要不要承認你根本不會做？」——誠實放棄扣 1 分，繼續拖扣 4 分。誠實比較划算
- **破產重整**：分數見底（< 20）時強制重整——留最急的 3 件、其餘放棄（可復原）、分數重設 50。最慘的時候給台階下，而不是讓你棄用
- **補記**：做了但沒列在清單上的事，一鍵補進帳裡。研究顯示人完成的事有 85% 從未被列進待辦清單——不記進來，你的守約率就是假的
- **三種語氣**（預設毒舌，可切教練／溫柔）：台詞庫 100+ 句，每一句都引用你本人的紀錄，不是隨機嘴砲
- 勾勾的臉色跟著信用分變：85 分眉開眼笑、60 分正常、40 分瞇眼、再低就翻臉
- **定時追討通知**（選單開啟）：早上 9 點、晚上 9 點，有逾期或今天到期的項目才會通知，台詞跟著語氣走。因為沒有伺服器，通知在「App 開著或掛在背景分頁」時最可靠（桌機尤其有效）；Android 裝到主畫面後另有背景喚醒（盡力而為）；**App 完全關閉時的真推播需要後端**，屬於之後會員機制的一部分。每次打開 App 也會補追當天還沒發的

## 亮點：約定足跡

這是「打勾勾」跟一般待辦 App 最不一樣的地方——它不只讓你打勾，還會記錄你**守約的歷史**。

- **完成慶祝**：打勾時會噴彩帶；把今天排定的事全部完成，慶祝會更盛大
- **連續達成天數**：每天至少完成一件就延續，斷了就歸零
- **守約率**：有設到期日的項目中，準時完成的比例
- **熱力圖**：近 17 週的完成密度，一眼看出自己的節奏（今天的格子有外框標記）
- **今日成果卡**：一鍵產生一張 1080×1350 的分享圖（自動套用你當下的配色），可下載 PNG 或直接複製到剪貼簿

足跡紀錄獨立於待辦本身，就算刪掉已完成的項目，歷史也不會消失。

## 安裝成 App（PWA）

打勾勾是一個 PWA，可以裝到手機或桌機的主畫面，開起來沒有網址列，**離線也能完整使用**。

- **iPhone / iPad**：用 Safari 開啟 → 點下方分享鈕 → 「加入主畫面」
- **Android / Chrome / Edge**：右上角選單會出現「安裝到主畫面」，或用網址列的安裝圖示
- **桌機**：同上，安裝後會像獨立 App 一樣有自己的視窗

長按主畫面圖示還有兩個捷徑：**新增約定**、**今日成果卡**。

離線能力由 Service Worker 提供：應用外殼採快取優先（背景自動更新），頁面本身採網路優先，斷網時回落到快取。有新版本時畫面會提示重新整理。

> 改動 `assets/` 或 `index.html` 後，記得把 `sw.js` 裡的 `VERSION` 加一，使用者才會拿到新版。

## 三個分頁

畫面拆成三頁，手機的分頁列固定在底部（像原生 App），桌機則排在頂部：

| 分頁 | 內容 |
| --- | --- |
| **今天** | 問候語、今日進度環、四格總覽、快速新增，以及**只有逾期與今天**的待辦。有逾期或今天到期時，分頁鈕會亮紅點 |
| **清單** | 搜尋、排序、分類 chip，加上**依日期分頁**（全部／逾期／今天／明天／本週稍後／之後／未排定／已完成），超過 20 筆再自動翻頁 |
| **足跡** | 連續達成、守約率、累計完成、熱力圖與成果卡 |

點「今天」頁的四格總覽會直接跳到清單頁對應的分頁。選到的分頁會記住，下次打開回到同一頁。

## 其他功能

- **新增／編輯／刪除**，含標題、備註、到期日、優先度（高／中／低）、分類
- **快速輸入語法**：一行搞定
  - `!高` `!中` `!低` → 優先度
  - `#工作` → 分類
  - `@今天` `@明天` `@後天` `@下週` `@2026-08-15` `@8/15` → 到期日
  - 例：`寫月報 !高 #工作 @明天`
- **自動分組**：已逾期 / 今天 / 明天 / 本週稍後 / 之後 / 未排定 / 已完成，每組可收合
- **篩選**：全部、今天、逾期、已完成，加上分類 chip 與全文搜尋
- **排序**：自訂順序（可拖曳）、到期日、優先度、建立時間
- **三組配色 × 淺深色**：奶油拿鐵、粉彩糖霜、螢光萊姆，預設跟隨系統

- **匯出／匯入 JSON 備份**（含足跡紀錄，以 id 去重）
- **刪除可復原**、**多分頁同步**、響應式版面（手機為底部彈出式表單）

## 鍵盤快速鍵

| 按鍵 | 功能 |
| --- | --- |
| `N` | 聚焦到新增輸入框 |
| `/` | 聚焦到搜尋框 |
| `T` | 切換淺色／深色 |
| `1` `2` `3` | 切換今天／清單／足跡 |

## 檔案結構

```
index.html            畫面結構 + 內嵌 SVG 圖示集 + 保底樣式
assets/styles.css     設計代幣（三組色盤 × 明暗）與所有樣式
assets/app.js         應用邏輯：狀態、儲存、分組、足跡、彩帶、成果卡、PWA
manifest.webmanifest  PWA 設定（名稱、圖示、捷徑、顯示模式）
sw.js                 Service Worker：離線快取
icons/                主畫面圖示（含 maskable 與 apple-touch-icon）
.nojekyll             讓 GitHub Pages 直接提供靜態檔
```

## 設計

視覺走「柔和暖色底 + 白色大圓角卡片 + 柔光陰影 + 粉彩色塊」的路線，圓角 12–34px，陰影分三階，所有顏色都抽成 CSS 變數，換色盤不需要動邏輯。

圖示使用 [Lucide](https://lucide.dev)（ISC License），路徑直接內嵌成 SVG sprite，不依賴 CDN，維持離線可用。

## 資料格式

```json
{
  "version": 3,
  "app": "pinky",
  "exportedAt": "2026-08-02T00:00:00.000Z",
  "todos": [
    {
      "id": "…",
      "title": "寫月報",
      "note": "",
      "done": false,
      "priority": "high",
      "category": "工作",
      "due": "2026-08-03",
      "createdAt": 1754092800000,
      "doneAt": null
    }
  ],
  "history": {
    "2026-08-02": { "done": 3, "withDue": 2, "onTime": 2 }
  },
  "credit": { "score": 70, "settledUntil": "2026-08-02", "bankruptAsked": "" }
}
```

匯入時以 `id` 判斷重複並自動略過，同一份備份匯入兩次不會產生重複項目；`history` 會以每日較大值合併。
